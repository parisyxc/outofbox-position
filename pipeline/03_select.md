# 03 — Select 7

1. Eligible: total score **≥ 2.0**.
2. Rank by score, then by target gap% (higher = more room), then by overlay (constructive > extended > euphoric).
3. Diversification: **max 4 per GICS sector**; prefer at least 3 sectors among the 7.
4. Names already in the ledger as `tracking` are re-scored; if still ≥2.0 they stay as **Continuing** and do not consume a "New" slot unless the plan changes.
5. If fewer than 7 eligible, publish fewer — never pad with a <2.0 name.
6. Name 2–3 **alternates** (next in rank) with a one-line reason each.
7. For every excluded name that scored ≥2.0, write a one-line exclusion reason (sector cap, extended, weaker gap).
