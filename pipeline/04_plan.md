# 04 — Trading Plan (conservative: stock + long calls)

## Plan type = f(score, overlay, catalyst)
| Score | Overlay | Plan |
|---|---|---|
| ≥ 2.5 | constructive (target > price by ≥3%) | **LONG STOCK** |
| ≥ 2.5 | constructive **+ dated catalyst inside 90 days** | **LONG STOCK + LONG CALLS** |
| ≥ 2.5 | extended (at high, target ≈ price) | **WATCH — alert at pullback level** |
| ≥ 2.5 | euphoric (price above targets) | **WATCH — do not chase** |
| 2.0 | any | **WATCH** |
| ≤ 1.5 | any | not selected |

## Levels (every pick gets all four)
- **Entry zone** — current price ±2–3%, or the pullback shelf for WATCH names
- **Hard stop** — below the breakout base / most recent swing low (typically 7–10% for stock)
- **Target** — analyst average as the base target; note the Street high as the stretch
- **Alert level** — for WATCH: the pullback price to buy, or the breakout price (with volume) to confirm

## Sizing & risk
- ≤ **5%** of account per name; ≤ **20%** per sector.
- **Long calls:** only when plan = LONG_STOCK+CALLS; 60–90 DTE, expiry **after** the catalyst; strike ATM to +5%; ≤ **1%** of account per call position; treat premium as fully at risk.
- No naked short options; no margin.

## Catalyst examples that qualify for calls
Earnings date inside expiry · FDA/regulatory decision date · guidance event · announced buyback start · dated contract award.
